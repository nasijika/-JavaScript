# 📚 การบ้าน JavaScript สำหรับว่าที่ Automation Tester

สวัสดีครับน้อง! ชุดการบ้านนี้จะพาน้องรู้จัก JavaScript ตั้งแต่พื้นฐาน
ไปจนถึงเรื่องที่จำเป็นต่อการทำ automation test (Playwright/Cypress) คือ
**Array → Object → Array of Objects → Async/Await/Promise**

จุดสำคัญ: น้องจะได้ฝึก **รัน test แล้วดูผลเขียว/แดง** ไปในตัว —
นี่แหละคืองานหลักของ automation tester เลย 😎

---

## 🛠 เตรียมตัว (ทำครั้งเดียว)

1. ติดตั้ง Node.js (เวอร์ชัน 18 ขึ้นไป) — เช็คด้วยคำสั่ง:
   ```bash
   node -v
   ```
2. เปิด terminal เข้ามาที่โฟลเดอร์นี้ (`js-homework`)

> ชุดนี้ใช้ test runner ที่ติดมากับ Node อยู่แล้ว **ไม่ต้อง `npm install` อะไรเลย**

---

## 📝 วิธีทำการบ้าน

แต่ละบทมี 3 ไฟล์:

| ไฟล์ | คืออะไร | น้องต้องทำอะไร |
|------|---------|----------------|
| `lesson.md` | บทเรียน + ตัวอย่าง | **อ่านก่อน** |
| `exercises.js` | โจทย์ | **เขียนคำตอบตรงนี้** |

(ตัวตรวจคือไฟล์ `check.js` ที่อยู่นอกโฟลเดอร์บท — ไม่ต้องยุ่งกับมัน)

ขั้นตอน:
1. อ่าน `lesson.md` ของบทนั้น
2. เปิด `exercises.js` แล้วเขียนโค้ดตรงที่เขียนว่า `// 👉 เขียนโค้ดตรงนี้`
3. รัน test ของบทนั้นเพื่อตรวจคำตอบ

---

## ▶️ คำสั่งรัน test

ตรวจทีละบท:
```bash
npm run test:01     # บท 1 Array
npm run test:02     # บท 2 Object
npm run test:03     # บท 3 Array of Objects
npm run test:04     # บท 4 Async / Await / Promise
```

ตรวจทั้งหมดทีเดียว:
```bash
npm test
```

## 🟢 อ่านผล ยังไง

- `✅` = ข้อนั้นผ่านแล้ว
- `❌` = ยังไม่ผ่าน จะบอกว่า **อยากได้** อะไร แต่โค้ดเรา **แต่ได้** อะไร

ตัวอย่างผล:
```
📘 บท 1 — Array
  ❌ sumAll([1,2,3]) = 6
      อยากได้ : 6
      แต่ได้  : [1,2,3]

สรุป: ✅ ผ่าน 0 ข้อ   ❌ ยังไม่ผ่าน 7 ข้อ
```
แปลว่า: เขาอยากได้ `6` แต่เราคืน `[1,2,3]` → แก้ให้บวกเลขก่อนค่อย return

## 🖨 อยาก console.log ดูค่า?
ใส่ `console.log(...)` ในฟังก์ชันได้เลย แล้วรัน test ตามปกติ —
ค่าจะปริ้นออกมาตรงๆ เหมือนรัน `node` ในเทอร์มินอล:
```js
function sumAll(numbers) {
  console.log("numbers =", numbers);   // 👈 ปริ้นออกมาให้เห็นเลย
  return ...;
}
```
